Back around the time we did SQL Bits, [Rob Sewell](http://sqldbawithabeard.com) spoke to [Richard Campbell](https://twitter.com/richcampbell) at [RunAs Radio](http://runasradio.com/Shows/Show/572).

The show, [Managing SQL Server using dbatools with Rob Sewell](http://runasradio.com/Shows/Show/572), is a fun and fantastic listen. Not only does Rob talk at length about the migration capabilities in dbatools, but also other cool things like CI/CD, containers and more. Check it out!
